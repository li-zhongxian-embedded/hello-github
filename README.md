# hello-github

我在本机第一次用 Git 建的仓库，用来练习 GitHub 的基本操作。

## 这个仓库演示了什么

- 用 `git init` 把一个普通文件夹变成 Git 仓库
- 用 `git add` + `git commit` 存了两次档
- 开了一条分支、在分支上改东西、再合并回来
- 用 `git log --oneline --graph` 看历史
